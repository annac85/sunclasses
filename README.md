# Sunclasses — Помощник классного руководителя

Бесплатное отечественное ПО для автоматизации рутинных задач классного руководителя: формирование характеристик, планов воспитательной работы, аналитических справок и социальных паспортов на основе выгрузок из электронного журнала. 

Программа работает локально на компьютере педагога, обеспечивая полное соответствие 152-ФЗ (персональные данные не покидают устройство).

> ⚠️ **Важно:** В этом репозитории публикуются **дистрибутивы программы** и **тестовые наборы данных**. Исходный код не публикуется: начиная с версии 1.5 проект распространяется по проприетарной модели.

## ⚡ Возможности

- **Импорт данных:** Автоматическое распознавание выгрузок из электронных журналов (ЭлЖур / Веб-Мост и др.).
- **Аналитика:** Мгновенный расчёт Успеваемости, Качества знаний (КЗ), Степени обученности (СОУ) и среднего балла.
- **Визуализация:** Тепловые карты успеваемости и графики динамики по классу и отдельным ученикам.
- **Генерация документов:** Создание характеристик, планов и справок в форматах `.docx` / `.odt` в один клик.
- **Два режима работы:** 
  1. *Шаблонный* (полностью офлайн, на основе чек-боксов).
  2. *ИИ-режим* (интеграция с GigaChat с обязательной анонимизацией ФИО перед отправкой запроса).
- **Безопасность:** Локальная база данных, работа без интернета, отсутствие необходимости в правах администратора.

## 💻 Установка

**Windows:**
1. Скачайте `Sunclasses_Setup_1.5.1.exe`.
2. Запустите установщик (права администратора **не требуются**).
3. Программа установится в папку пользователя. При удалении программы локальная база данных сохраняется.

**Linux (в т.ч. РЕД ОС):**
1. Скачайте архив `Sunclasses-1.5.1-linux-x86_64-onedir.tar.gz`.
2. Распакуйте его в любую удобную папку.
3. Перейдите в распакованную папку и запустите исполняемый файл.
4. Для просмотра сгенерированных документов используйте LibreOffice или Р7-Офис / OnlyOffice.

## 🤖 ИИ-генерация (GigaChat) и 152-ФЗ

Для использования ИИ-режима необходим бесплатный API-ключ GigaChat (получается на [developers.sber.ru](https://developers.sber.ru/)). 
- Бесплатного лимита токенов хватает примерно на **2000 документов+**
- **Архитектурная анонимизация:** Перед отправкой запроса в нейросеть программа автоматически заменяет ФИО учеников и название школы на индексы (например, `Ученик_001`). Нейросеть не получает и не обрабатывает персональные данные. Имя подставляется обратно уже на вашем компьютере.
- Программа **полностью работоспособна без ключа ИИ** (все расчёты, импорт и шаблонная генерация доступны офлайн).
