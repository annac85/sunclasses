# Sunclasses — помощник классного руководителя

Бесплатное отечественное ПО для классных руководителей: формирует характеристики учащихся, планы воспитательной работы, аналитические справки и отчёты из выгрузок электронного журнала. Работает локально на компьютере учителя; персональные данные учащихся не покидают ПК (152-ФЗ).

> ⚠️ В этом репозитории публикуются **дистрибутивы программы** (раздел Releases).
> Исходный код не публикуется: с версии 1.5 проект распространяется по проприетарной модели.

## Возможности

- Импорт оценок из электронного журнала (ЭлЖур / Веб-Мост; 4 варианта форматов выгрузки)
- Расчёт КЗ и СОУ, тепловые карты успеваемости класса и каждого ученика
- Генерация характеристик, планов воспитательной работы, аналитических справок (.docx, .odt)
- Два режима на выбор педагога: ИИ-генерация (GigaChat, с анонимизацией данных) и шаблонный режим без ИИ
- Локальная база данных, работа без интернета и без прав администратора
- Windows и Linux (проверено на РЕД ОС 8.0.2)

## Установка

**Windows:** запустите установщик и следуйте инструкциям. Программа ставится в папку пользователя, права администратора не требуются; данные при удалении программы сохраняются.

**Linux:** распакуйте архив в любую папку, перейдите в неё и запустите исполняемый файл. Для просмотра готовых документов подойдут LibreOffice или OnlyOffice.

## Системные требования

- ОС: Windows 10/11 или Linux x86_64 (проверено на РЕД ОС 8.0.2, ядро 6.12)
- ОЗУ: 4 ГБ (оптимально 8 ГБ)
- Свободное место: ≈ 500 МБ
- Офисный пакет: LibreOffice / OnlyOffice (или MS Office 2016+)
- Интернет: только для опциональной ИИ-генерации

## ИИ-генерация (GigaChat)

Для режима ИИ нужен бесплатный API-ключ GigaChat (получается на сайте разработчика); бесплатного лимита токенов хватает примерно на 2000 документов. Ключ хранится только на компьютере пользователя. Без ключа программа полностью работоспособна: вся аналитика, импорт и шаблонная генерация доступны офлайн. При ИИ-генерации применяется анонимизация: нейросеть не получает ФИО учащихся (152-ФЗ).
